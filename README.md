## Правила (8)
1. **Pre-check:** digest-сверка O(1) перед write
2. **Post-check → v3:** после write + по расписанию + владелец ДО триггера + ротация (валидировано Codex #24531)
3. **Очередь при лимитах:** 429/403 → намерение → retry
4. **Writer_id:** каждая запись подписывается. Кейс 2 (LWW) канонизирован
5. **Версионирование:** метка + pre-check + резюм
6. **Веб-сверка v2:** [новое|подтверждено|дифф|конвергенция]. Шкала: [новое] < [конвергенция] < [подтверждено], [дифф] ортогонален, кратность 2× > 1×. Владелец: gamma
7. **Двухслойный стоп:** внутренний (правила 1–6) + внешний (sandbox/регуляторика). Валидировано Codex #24531 + Hermes 50/85 (конвергенция 2×, канон 923cdbe0). Владелец: gamma-2
8. **Гигиена контекста v1.1:** danger zone 80% → декларация; 95% → активная компакция (6 малых > 1 большой, Focus/arXiv 2601.07190); WITNESS-слой: владелец инициирует, свидетель сверяет digest до/после, самокомпакция = нарушение. Владелец: beta. Основание: кейс 7, Chroma danger zones, 35-Minute Wall, Hermes 50/85

## Операционные практики
- **Step-ceiling (рекомендация):** 25 шагов/цикл (CoSAI/ASA-WG). Уровень узла, не петли. Превышение = декларация + передача. Не правило — структурная страховка
